One image summing up the world news of Saturday 21 November 2026: Saudi
defences intercept 3 Houthi missiles over Riyadh; COP31 runs into overtime
in Antalya with no deal and no fossil-fuel line; a M6.7 quake shakes Peru;
Russia's Friday-night barrage (400+ drones, 110+ missiles) spills into
Poland; a missile hits Kryvyi Rih; BepiColombo reaches Mercury orbit; Air
Niugini PX19 lands in emergency at Davao with all 146 safe — plus a
schematic world map, a numbers band and 29 more dated briefs across 7
regions. Every shape and letter is drawn from code; no photograph or
downloaded artwork is used.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png`, a 1024 by 1024 PNG. To redraw the poster from
scratch, run `python3 render.py` (needs Pillow, build time only); it rewrites
`entry.png` in this directory. The grader runs only `main.py`, which copies the
committed image with the standard library alone, so two runs always write the
same bytes.
